Голосовой AI-агент первой линии: звонок по шагам

Как агент принимает входящий звонок и сам подтверждает интернет-заказ. Всё работает на ваших серверах с GPU. Модель не подключена к 1С напрямую: она вызывает только разрешённые операции через изолированный шлюз, а каждый звонок попадает в базу структурированной записью.

ТелефонияSIP-транк, Asterisk / FreeSWITCH, очередь, перевод на оператора
РечьРаспознавание (Whisper) и синтез голоса — локально, потоково
LLMЛокальная модель понимает запрос и выбирает операцию
ШлюзБелый список операций, проверка параметров, журнал
1СОбмен только через шлюз: заказы, статусы, слоты доставки
Клиентраспознано

«Здравствуйте, я вчера заказывал диван, когда привезут?»

asr: 1,1 с · уверенность 0,93 · номер +7 9•• ••• •• 41
LLMнамерение

Определяет тему и нужную операцию — без ответа «из головы»

{"intent": "статус_доставки", "need": "найти заказ по номеру телефона"}
Шлюзоперация

Разрешённый запрос к 1С через шлюз

get_orders_by_phone(phone="+79••••••41", days=14)
→ заказ № 4512 от 26.11, статус «Собран», доставка 29.11, слот 10:00–14:00

Модель видит только ответ шлюза. Прямого доступа к базе 1С у неё нет.

Агентсинтез речи

«Ваш заказ 4512 собран, доставка в субботу, 29 ноября, с 10 до 14. Удобно или перенести?»

Итогзапись звонка

Каждый контакт — структурированная запись, ни один лид не теряется

{"тема": "статус доставки", "заказ": 4512, "решено": true,
 "оператор": false, "длительность": "0:48", "запись": "call_2026-11-28_1032.wav"}

Вопрос вне сценария, жалоба или «позовите человека» — перевод на оператора с краткой выжимкой разговора.

Шлюзочередь обзвона

Новые интернет-заказы забираются из 1С по расписанию

get_unconfirmed_orders() → 23 заказа · звонки 9:00–20:00 · 3 попытки
Агентсинтез речи

«Здравствуйте! Это магазин, звоню подтвердить заказ 4530: шкаф-купе, доставка в понедельник. Подойдёт слот с 14 до 18?»

Клиентраспознано

«Лучше утром, после десяти».

Шлюзоперация

Свободные слоты и запись — только через шлюз

get_free_slots(date="2026-12-01", after="10:00") → 10:00–14:00
set_delivery_slot(order=4530, slot="10:00–14:00", confirmed_by="voice")
→ ok · статус в 1С «Подтверждён»
Итогзапись звонка
{"заказ": 4530, "подтверждён": true, "слот": "01.12 10:00–14:00", "попытка": 1}

Не дозвонились за 3 попытки — задача менеджеру в 1С, а не тишина.

Принципы

Изолированный контурLLM, распознавание и синтез речи — на ваших GPU-серверах; наружу данные не уходят.
Шлюз вместо прямого доступаБелый список операций, проверка параметров, журнал каждого вызова; запись в 1С — только разрешёнными операциями.
Задержка ответаПотоковое распознавание и синтез, цель — до 1–1,5 с от конца фразы клиента до начала ответа.
Человек рядомПеревод на оператора по ключевым словам, по неуверенности модели и по просьбе клиента.
Контрольные звонкиНабор записанных сценариев прогоняется после каждого изменения до выкладки.

Пример собран под ваш заказ: заказы, номера и слоты вымышленные. Схема — предложение для обсуждения; в аудите сверю её с вашей телефонией, 1С и серверами.
